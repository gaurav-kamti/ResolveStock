# ResolveStock

A full-stack inventory and business management application built with the MERN stack.

## Tech Stack

### Frontend

- React
- Vite
- Bootstrap / Custom CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

## Core Modules

- Inventory Management
- Products and Categories
- Customers and Suppliers
- Purchase and Sales Invoices
- Purchase and Sales Returns
- Payment and Receipt Vouchers
- Reports and Exports

## Project Structure

- `client/` - Frontend application
- `server/` - Backend API

## Development Status

Project setup and initial backend database connection completed.
